# 素材放置说明

## 背景视频

请放入以下任一文件：

```text
home-background.mp4
home-background.webm
```

## 主题图片

建议把 6 张图片放入本目录，并使用以下文件名：

```text
space-panorama-1.jpg
rocket-launch-1.jpg
rocket-launch-2.jpg
feitian-1.jpg
feitian-astronaut.jpg
space-panorama-3.jpg
```

如果图片格式不同，请同步修改 `styles.css` 中对应的 `background-image` 路径。
